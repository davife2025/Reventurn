## Session 3: xlayer-assets

**Date:** 2026-09-20

**Goal:** Real, live X Layer integration — list tokenized US stocks (xStocks) on X Layer with their on-chain contract addresses, satisfying the hackathon's "Build a Market" track requirement (working X Layer integration + contract addresses + technical links). No hardcoded addresses anywhere — every address is resolved live from OKX's own API at request time.

**Important finding before any code was written (worth reading before you look at anything else):** I initially assumed I'd need to hardcode a handful of known xStocks contract addresses on X Layer. Research showed that's not safely possible — there's no public page that prints X Layer xStocks contract addresses, and the one OKX endpoint that would return them requires an authenticated API key (confirmed independently by another team's public research into this exact same problem, hit while researching this session). Rather than guess plausible-looking addresses or copy addresses out of an unverified third-party GitHub repo, I found OKX's official **RWA Token List API** (`GET /api/v6/dex/market/rwa/tokens`), which is free (100K calls/month, no payment needed) and returns xStocks contract addresses live, per-chain, as part of its normal response. The integration is built around that instead — it resolves addresses at request time rather than storing any.

**Files added:**
- `packages/types/src/assets.ts` — `TokenizedAsset`, `TokenizedAssetList`

- `apps/api/src/routes/assets.ts` — `GET /assets`, calls the RWA Token List API filtered to `chainIndex=196` (X Layer) + `issuer=36` (xstocks), normalizes OKX's response (including converting their `""` empty-string sentinel to `null` rather than `NaN`), builds an explorer URL per token

- **Signature element:** the ticker rail — a persistent thin strip showing the current highest-yielding currency and spread at a glance. Real component, reads live data, not decorative.
